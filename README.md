# Academic website — Aleksandar Trklja

A minimalist, responsive static website with Home, Research, Publications, Teaching & Activities, Research Insights, and Contact pages.

## Preview
Open `index.html` in a browser.

## Update and publish
Edit the relevant `.html` file and `style.css` as needed. To add a new section, create a new HTML page and add a navigation link to each existing page. Publish the files in this ZIP to a public GitHub repository and enable GitHub Pages (Settings → Pages → Deploy from a branch, `main`, `/ (root)`). No hosting fee is required for GitHub Pages public repositories.

The portrait is `assets/aleksandar-trklja-portrait.jpg`. No build process or external dependencies are required.
